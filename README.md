# 🌍✨ **Satellite Filters Data Collection** ✨🌍  

Dive into the world of **satellite data analysis** with this exciting project! We collect, process, and visualize data from three powerful sources:  

🌟 **MODIS LST**  
🌟 **MODIS AOD**  
🌟 **Sentinel-5P**  

From tracking Land Surface Temperature (LST) to monitoring Air Quality, this project provides valuable insights at the intersection of data science and geospatial technology. 🚀  

---

## 📚 **About the Project**  

🔹 **What We Do**:  
We harness the power of Google Earth Engine and geospatial libraries to process satellite data, extract meaningful insights, and visualize them through stunning time-series graphs.  

🔹 **Key Features**:  
- 🌐 Create **1 km x 1 km grids** for precise data extraction.  
- 📂 Export clean datasets into **CSV files**.  
- 📊 Visualize trends with **interactive time-series graphs**.  

---

## 🌟 **Highlights**  

✨ **Multi-Satellite Integration**: Analyze data from three powerful sources—MODIS and Sentinel-5P.  
✨ **Flexible ROI Analysis**: Generate grids for any **region of interest (ROI)** with ease.  
✨ **Beautiful Visuals**: Stunning graphs to explore time-series trends effortlessly.  

---

## 📂 **Folder Structure**  

Here's how the repository is organized:  

📁 **AQAi Frontend**: Interactive tools for visualizing extracted data.  
📁 **Extracted CSV Files**: Organized datasets ready for analysis:  
  - `MODIS_LST_DATA.csv`  
  - `MODIS_AOD_DATA.csv`  
  - `SENTINEL_5P_DATA.csv`  
📁 **Notebooks**: Jupyter notebooks for data extraction and visualization.
